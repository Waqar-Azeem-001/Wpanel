Decisions needed before building

  1. Rail labels: small text under each icon (as drawn), or icons only with a tooltip?
  2. Home to-dos: which items matter most to you? Draft: unpaid invoice, service expiring in 14 days, website not created, domain not pointing, open ticket reply.
  3. Website menu groups: are the ten groups right, or should some be merged (for example Files and Databases together)?
  4. Default look: light or dark by default? (Both exist; the choice is only the starting one.)
  5. Staff area: keep it as it is for now and apply this shell only to customers?
